# Modelo

Todo lo relacionado a elegir y entender el modelo de este piloto — no solo la ficha técnica, también de dónde viene y por qué.

- **`fundamentacion-modelo.md`** — **qué es Qwen, de dónde viene, historia real verificada de la línea Coder, y el esquema completo de la decisión** (filtro por filtro) que llevó a elegirlo para este equipo. Es el documento a leer antes de instalar, para poder explicar la elección, no solo ejecutarla.
- **`modelo-elegido.md`** — decisión técnica de modelo para este hardware (Qwen 2.5 Coder 7B): VRAM, velocidad, cuantización, comparación con alternativas, y confirmación de que no existe todavía un Qwen3-Coder más chico que lo reemplace.
- **`hardware-real.md`** — specs del equipo y qué modelo cabe realmente, cruzado contra la tabla de VRAM de `../../../ia-local/docs/modelos.md`.
