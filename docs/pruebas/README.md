# Pruebas

Cómo se evalúa el piloto una vez instalado — calidad de respuestas y rendimiento real son cosas distintas, cada una con su propio protocolo.

- **`01-plan-pruebas.md`** — protocolo de evaluación y criterios de éxito de este piloto (calidad de respuestas, no velocidad).
- **`02-pruebas-rendimiento.md`** — esquema de pruebas de estrés post-instalación (tok/s real, estabilidad bajo carga, límite real de contexto) — distinto de `01-plan-pruebas.md`.
- **`resultados.md`** *(no existe todavía)* — se crea una vez haya pruebas reales corridas en el equipo, con datos medidos de primera mano (no de un sitio de benchmarks de terceros).
